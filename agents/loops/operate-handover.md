# Loop: operate & handover

## Goal

Operators run Central Design Agent + knowledge captures without Studio as the polish path.

## Steps

1. Share `AGENTS.md`, `docs/architecture.md`, `agents/loops/central-design-cycle.md`.
2. Confirm Ceramic adapter commands work in their environment.
3. Supervised: one small cycle (build → capture → learning review → refine).
4. Draw the line: further design tweaks are operator-owned via this loop.

## Done when

Operator can run the cycle; Studio not default for minor UI tweaks.
