# Skill: capture failure

## Steps

1. Create `knowledge/failures/DK-YYYYMMDD-short-slug.md`.
2. Record: symptom, root cause, incorrect agent/human action, correct path, prevention.
3. Catalog row with tags (e.g. `rtl`, `tokens`, `invented-api`).
4. Mark promote? usually **yes** if it prevents repeat mistakes.

## Done when

Failure is findable via catalog; not only buried in chat.
