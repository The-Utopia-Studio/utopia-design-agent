# Loop: project build

## Goal

Ship one scoped design outcome with Ceramic — no learning-review here (parent owns that).

## Steps

1. Confirm scope from parent (or state it).
2. `use-ceramic` discovery for every UI surface.
3. Implement in the **target product** (or agreed sandbox) — not by forking Ceramic core unless the goal is a Ceramic PR.
4. Rams on touched UI.
5. Doctor / relevant checks green for the consumer or Ceramic change set.

## Done when

- [ ] Scope checklist complete or blocked with reason
- [ ] No invented Ceramic APIs
- [ ] Evidence paths listed for the learning review

## Forbidden

- Expanding scope mid-build without human OK
- Editing Ceramic “while we’re here” without it being the goal
